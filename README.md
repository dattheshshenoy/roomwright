# WebMCP Challenge Project

Entry for **The WebMCP Challenge** (https://webmcp.devpost.com) — build a
WebMCP-powered web application that lets humans and AI agents interact,
collaborate, and create together.

- **Submission deadline:** Sept 3, 2026, 1:00 PM PDT
- **Status:** scaffolding — concept TBD (see [NOTES.md](./NOTES.md))

## What is WebMCP?

An open standard (`webmachinelearning/webmcp`) that lets a website expose
structured **tools** — callable functions with JSON schemas — to AI agents
running in the browser (ChatGPT's in-app browser, or Chrome 149+ with WebMCP
enabled). The human stays in the loop; the agent invokes page-provided tools.
